## 1. Problem Logging Standard

Every problem analyzed or solved in this directory must use `problem-template.md` as its structure and record:

1. **Problem Name & URL**: Exact title and canonical Codeforces problem link.
2. **Official Rating**: Official difficulty tag ($800 - 3500$).
3. **Core Algorithmic Concept**: Primary paradigm (e.g. Binary Search on Answer, 2D Prefix Sums, Tree Diameter).
4. **Secondary Concepts**: Auxiliaries (e.g. Coordinate Compression, Modulo Inverses, Disjoint Set Union).
5. **Dates**: Date attempted and Date solved.
6. **Attempt Count**: Number of submissions prior to Accepted (AC).
7. **Independence**: Solved Independently vs. Solved with Editorial / Help.
8. **Time Taken**: Time from reading to AC.
9. **Mistakes & False Paths**: Exact misconceptions, WA reasons, or TLE causes.
10. **Key Insight / Learning**: The pivotal mathematical or structural observation that unblocked the solution.
11. **Revision Schedule**: Active recall date.

## 2. Rating Band Objectives & Mental Models

- **800 - 1000**: Elimination of implementation hesitation, 1-indexing vs 0-indexing fluency, basic greedy choices.
- **1100 - 1300**: Invariant identification, two pointers, frequency counting, standard prefix sums, binary search.
- **1400 - 1600**: Multi-step reductions, standard dynamic programming, tree traversals, shortest paths, bitwise reasoning.
- **1700 - 1900**: Non-trivial DP optimizations, Range query structures (Segment Trees), constructive mathematical properties, game theory.
- **2000+**: Unorthodox combinations, flow modeling, centroid decomposition, persistent data structures, advanced math (FFT/NTT).
