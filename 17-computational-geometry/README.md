# 17. Computational Geometry

This module covers 2D and 3D geometric algorithms, vector algebra, polygon properties, and sweep-line paradigms.

---

## Subtopics & Planned Modules

1. **`points-and-vectors/`**: 2D Point class, vector addition, dot product, 2D cross product (`ccw`).
2. **`orientation-and-intersections/`**: Collinear, clockwise, counter-clockwise checks, line and segment intersection tests.
3. **`polygon-area/`**: Shoelace formula (Gauss's area formula), Pick's Theorem.
4. **`convex-hull/`**: Andrew's Monotone Chain algorithm, Graham scan in $O(N \log N)$.
5. **`closest-pair-of-points/`**: Divide-and-conquer algorithm in $O(N \log N)$ and randomized sweep-line.
6. **`rotating-calipers/`**: Finding polygon diameter, maximum distance pair in $O(N)$ on convex hulls.
7. **`point-in-polygon/`**: Ray casting algorithm and winding number test in $O(N)$, $O(\log N)$ for convex polygons.
8. **`sweep-line-geometry/`**: Segment intersection sweep line using balanced BST.
