# 15. Probability and Statistics

This module covers discrete probability, expected values, linearity of expectation, and Markov chains.

---

## Subtopics & Planned Modules

1. **`probability-fundamentals/`**: Sample spaces, independent events, conditional probability, Bayes' Theorem.
2. **`expected-value-linearity/`**: Linearity of expectation $\mathbb{E}[X + Y] = \mathbb{E}[X] + \mathbb{E}[Y]$ without independence.
3. **`indicator-variables/`**: Counting expected occurrences and inversions via indicator variables.
4. **`markov-chains-random-walks/`**: State transition matrices, expected steps to absorption, Gambler's Ruin.
5. **`probabilistic-dp/`**: Dynamic programming where states represent probabilities or expected values.
6. **`randomized-algorithms/`**: Las Vegas vs. Monte Carlo algorithms, Miller-Rabin primality test.
