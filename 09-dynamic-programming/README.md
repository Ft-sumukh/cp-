# 09. Dynamic Programming (DP)

This module covers optimal substructure, overlapping subproblems, memoization, iterative tabulation, and modern DP optimizations.

---

## Subtopics & Planned Modules

1. **`dp-introduction/`**: Memoization (top-down) vs Tabulation (bottom-up), state dimension reduction.
2. **`1d-and-2d-dp/`**: Classic linear transitions, state space modeling.
3. **`grid-dp/`**: Path counting, minimum cost paths, obstacle avoidance.
4. **`knapsack-variants/`**: 0/1 Knapsack, Unbounded Knapsack, Bounded Knapsack with binary splitting.
5. **`longest-increasing-subsequence/`**: $O(N^2)$ to $O(N \log N)$ optimization using patience sorting / binary search.
6. **`longest-common-subsequence/`**: LCS, Longest Common Substring, sequence alignment.
7. **`interval-dp/`**: Matrix chain multiplication, merging adjacent elements in $O(N^3)$.
8. **`tree-dp/`**: Subtree aggregations, maximum independent set on trees.
9. **`rerooting-dp/`**: Dynamic programming with changing tree roots.
10. **`bitmask-dp/`**: Traveling Salesperson Problem (TSP), subset assignment in $O(2^N \cdot N)$.
11. **`submask-enumeration/`**: Iterating submasks of masks in $O(3^N)$.
12. **`digit-dp/`**: Counting integers satisfying properties in range $[L, R]$.
13. **`divide-and-conquer-dp/`**: Quadrangle inequality and 1D monotone split point optimization.
14. **`convex-hull-trick/`**: Dynamic and static CHT for linear transitions $dp[i] = \min(m_j x_i + c_j)$.
15. **`knuth-optimization/`**: Reducing interval DP from $O(N^3)$ to $O(N^2)$ via monotonicity of optimal split points.
16. **`sos-dp/`**: Sum Over Subsets in $O(N \cdot 2^N)$ using multidimensional prefix sums.
