# 05. Sorting Algorithms & Comparator Design

This module covers comparison and non-comparison sorting algorithms, stability, and strict weak ordering semantics.

---

## Subtopics & Planned Modules

1. **`merge-sort/`**: Divide-and-conquer, counting inversions in $O(N \log N)$.
2. **`quick-sort/`**: Pivot selection, Dutch National Flag (3-way partitioning), worst-case avoidance.
3. **`counting-and-radix-sort/`**: Non-comparison linear time sorting $O(N + K)$ for bounded integers.
4. **`heap-sort/`**: In-place heap construction and sorting mechanics.
5. **`custom-sorting/`**: Struct comparators, lambda comparators, strict weak ordering proof.
6. **`sorting-invariants/`**: Invariant maintenance, stability properties, sorting-based greedy solutions.
