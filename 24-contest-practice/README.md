# Contest Practice & Virtual Simulation Log

This directory tracks live contest performances, virtual Codeforces rounds, AtCoder Beginner/Regular contests, and post-contest upsolving.

---

## Contest Protocol

1. **Simulate Real Conditions**: No looking at hints, editorials, or external code during the round duration (e.g. 2 hours).
2. **Speed vs Accuracy Invariant**: Avoid hasty submissions on problem A/B to prevent penalty points (+10 mins per WA).
3. **Mandatory Upsolving**:
   - Every unsolved problem within $+1$ of your rating threshold must be solved within 48 hours post-contest.
   - Read the official editorial, identify the single mental leap you missed, and write the solution from scratch without copying.
