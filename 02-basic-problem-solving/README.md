# 02. Basic Problem-Solving Paradigms

This module covers fundamental problem-solving patterns that form the bedrock of Stage 1 competitive programming.

---

## Subtopics & Planned Modules

1. **`prefix-sums/`**: 1D static range sum queries in $O(1)$ time, prefix XOR, prefix products.
2. **`prefix-sums-2d/`**: 2D grid range sum queries via inclusion-exclusion in $O(1)$.
3. **`difference-arrays/`**: Range updates in $O(1)$ with single prefix sum reconstruction in $O(N)$.
4. **`two-pointers/`**: Linear time $O(N)$ pair finding, subarray conditions, monotonic pointer movements.
5. **`sliding-window/`**: Fixed and variable length window invariants, deque-based sliding window minimums.
6. **`coordinate-compression/`**: Mapping large sparse coordinate domains ($X_i \le 10^9$) to dense ranks ($[0, N-1]$).
7. **`greedy-algorithms/`**: Greedy choice property, exchange arguments, interval scheduling.
8. **`simulation-constructive/`**: Invariant preservation, parity tricks, backward reasoning in constructive problems.
