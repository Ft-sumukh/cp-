# 16. Game Theory

This module covers combinatorial game theory, normal play convention, game graphs, and Sprague-Grundy theorem.

---

## Subtopics & Planned Modules

1. **`game-states/`**: Winning (N-positions) vs. Losing (P-positions), backward induction on DAGs.
2. **`game-of-nim/`**: Bouton's Theorem, XOR sum (nim-sum) invariant analysis.
3. **`sprague-grundy-theorem/`**: Grundy values, Minimum Excluded value (mex), game decomposition into independent Nim piles.
4. **`subtraction-games/`**: Periodic Grundy value analysis and pattern discovery.
5. **`partizan-games/`**: Minimax game trees, alpha-beta pruning concepts.
