# 06. Basic Data Structures

This module covers linear and semi-linear data structures, amortized push/pop analysis, and monotonic variants.

---

## Subtopics & Planned Modules

1. **`stacks-and-queues/`**: Array-based and dynamic implementations, circular buffer queues.
2. **`deques/`**: Double-ended queues, cache locality, sliding window mechanics.
3. **`monotonic-stack/`**: Next Greater Element, Next Smaller Element, Largest Rectangle in Histogram in $O(N)$.
4. **`monotonic-queue/`**: Sliding Window Maximum/Minimum in $O(1)$ amortized time.
5. **`binary-heaps/`**: Array-based binary heaps, percolate-up/percolate-down operations.
6. **`hash-tables/`**: Open addressing vs chaining, collision resolution, anti-hash defense.
