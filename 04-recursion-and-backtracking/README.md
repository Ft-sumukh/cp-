# 04. Recursion and Backtracking

This module covers recursive decompositions, state space trees, and search pruning strategies.

---

## Subtopics & Planned Modules

1. **`recursion-fundamentals/`**: Base cases, call stack mechanics, recursion tree visualization.
2. **`subset-generation/`**: Generating $2^N$ combinations iteratively and recursively.
3. **`permutation-generation/`**: Generating $N!$ orderings with backtracking and `std::next_permutation`.
4. **`backtracking-pruning/`**: N-Queens, Sudoku solvers, branch-and-bound bounding functions.
5. **`meet-in-the-middle-search/`**: Bi-directional BFS and search space splitting.
