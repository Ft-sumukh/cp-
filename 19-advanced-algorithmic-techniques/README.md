# 19. Advanced Algorithmic Techniques

This module covers query optimization paradigms, multidimensional divide-and-conquer, and specialized techniques.

---

## Subtopics & Planned Modules

1. **`sqrt-decomposition-techniques/`**: Block decomposition on arrays and trees, batch update strategies.
2. **`mos-algorithm-variations/`**: Standard Mo's, Mo's with updates ($O(N^{5/3})$), Mo's on trees (Euler tour).
3. **`parallel-binary-search/`**: Solving multiple independent binary search queries simultaneously in $O((N + Q) \log(\text{range}))$.
4. **`cdq-divide-and-conquer/`**: Offline 3D/4D partial order queries via divide-and-conquer.
5. **`small-to-large-merging/`**: Merging smaller sets into larger ones guaranteeing $O(N \log^2 N)$ total complexity.
6. **`bitset-optimizations/`**: Constant factor acceleration ($1/64$) using `std::bitset` for transitive closure and subset sum.
7. **`randomized-hashing/`**: Zobrist hashing for board games, multiset hashing.
8. **`matroid-intersection/`**: Matroid greedy algorithm and intersection fundamentals.
