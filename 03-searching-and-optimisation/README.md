# 03. Searching and Optimisation

This module covers discrete and continuous search spaces, monotonic predicates, and search space reductions.

---

## Subtopics & Planned Modules

1. **`binary-search/`**: Invariant formulation (`low <= high` vs `low < high`), predicate formulation, `std::lower_bound` vs `std::upper_bound`.
2. **`binary-search-on-answer/`**: Monotonic feasibility functions `check(mid)`, min-max optimization problems.
3. **`ternary-search/`**: Unimodal functions, finding extreme values (min/max) over convex/concave curves.
4. **`parallel-binary-search/`**: Processing multiple queries simultaneously using binary search sweeps.
5. **`meet-in-the-middle/`**: Halving exponent $2^N \to 2^{N/2}$ with hash table lookup or binary search.
