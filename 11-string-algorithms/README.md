# 11. String Algorithms

This module covers string matching, rolling hashing, automaton-based text search, and suffix structures.

---

## Subtopics & Planned Modules

1. **`string-hashing/`**: Polynomial rolling hash, double hashing (preventing collisions), $O(1)$ substring hash queries.
2. **`prefix-function-kmp/`**: Knuth-Morris-Pratt algorithm, prefix function computation in $O(N)$, string period analysis.
3. **`z-algorithm/`**: Z-function computation in $O(N)$ for pattern matching and border identification.
4. **`manacher-algorithm/`**: Linear time $O(N)$ identification of all palindromic substrings.
5. **`trie/`**: Prefix tree for string set search and binary bitwise tries for maximum XOR pair queries.
6. **`aho-corasick/`**: Multi-pattern matching automaton in $O(N + M + K)$ with dictionary and failure links.
7. **`suffix-automaton/`**: Directed acyclic word graph (DAWG) encoding all substrings in $O(N)$ states and transitions.
8. **`suffix-array-lcp/`**: Suffix array construction in $O(N \log N)$ and Kasai's algorithm for Longest Common Prefix (LCP).
