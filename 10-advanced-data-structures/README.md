# 10. Advanced Data Structures

This module covers range query data structures, persistent memory layouts, tree structures, and offline query algorithms.

---

## Subtopics & Planned Modules

1. **`fenwick-tree/`**: Binary Indexed Tree (BIT) for point updates and prefix sums in $O(\log N)$ time and $O(N)$ space.
2. **`segment-tree/`**: Point update, range query Segment Tree (iterative and recursive).
3. **`lazy-propagation/`**: Range update and range query in $O(\log N)$ via deferred evaluation.
4. **`sparse-table/`**: Static Range Minimum Query (RMQ) in $O(1)$ query with $O(N \log N)$ preprocessing.
5. **`persistent-segment-tree/`**: Versioned tree states sharing unchanged paths, solving range $K$-th element queries in $O(\log N)$.
6. **`merge-sort-tree/`**: Segment Tree storing sorted subarrays for counting elements in range $[L, R]$ greater than $X$.
7. **`treap-cartesian-tree/`**: Randomized balanced binary search tree, implicit treaps for array split/merge operations.
8. **`sqrt-decomposition/`**: Block decomposition processing queries in $O(\sqrt{N})$.
9. **`mos-algorithm/`**: Offline query processing via Hilbert curve or block sorting in $O((N + Q)\sqrt{N})$.
10. **`dsu-on-tree/`**: Small-to-large merging on trees answering subtree queries in $O(N \log N)$.
11. **`li-chao-tree/`**: Segment Tree maintaining line segments for dynamic Convex Hull queries in $O(\log N)$.
12. **`link-cut-tree/`**: Dynamic tree data structure maintaining forest connectivity and path queries in $O(\log N)$ amortized.
