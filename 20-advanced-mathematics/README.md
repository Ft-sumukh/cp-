# 20. Advanced Mathematics

This module covers linear algebra over finite fields, matrix exponentiation, and polynomial transformations.

---

## Subtopics & Planned Modules

1. **`matrix-exponentiation/`**: Transition matrices for linear recurrences (Fibonacci, DP counting) in $O(K^3 \log N)$.
2. **`gaussian-elimination/`**: Solving systems of linear equations over $\mathbb{R}$, finding matrix rank and determinant in $O(N^3)$.
3. **`gaussian-elimination-f2/`**: Gaussian elimination over $\mathbb{F}_2$ using `std::bitset` in $O(N^3 / 64)$, XOR basis.
4. **`fast-fourier-transform/`**: Cooley-Tukey FFT for polynomial multiplication in $O(N \log N)$ over complex numbers.
5. **`number-theoretic-transform/`**: NTT over finite fields modulo $998244353$ using primitive roots of unity.
6. **`lagrange-interpolation/`**: Evaluating degree $D$ polynomial at $X$ in $O(D)$ for contiguous integer inputs.
