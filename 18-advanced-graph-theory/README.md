# 18. Advanced Graph Theory & Network Flows

This module covers flow networks, matching algorithms, vertex/edge connectivity, and duality theorems.

---

## Subtopics & Planned Modules

1. **`network-flow-fundamentals/`**: Residual networks, augmenting paths, Max-Flow Min-Cut Theorem.
2. **`edmonds-karp-algorithm/`**: BFS-based augmenting path algorithm running in $O(V E^2)$.
3. **`dinic-algorithm/`**: Level graphs and blocking flows running in $O(V^2 E)$, $O(E \sqrt{V})$ on unit networks.
4. **`bipartite-matching/`**: Hopcroft-Karp algorithm running in $O(E \sqrt{V})$, König's Theorem (Max Matching = Min Vertex Cover).
5. **`min-cost-max-flow/`**: Successive shortest path algorithm using SPFA or Dijkstra with potentials.
6. **`connectivity-cuts/`**: Global min-cut (Stoer-Wagner algorithm), vertex cuts, edge cuts.
7. **`2-sat-applications/`**: Implication graphs, strongly connected components, variable assignment.
