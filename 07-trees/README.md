# 07. Tree Algorithms

This module covers rooted and unrooted tree representations, traversals, dynamic programming on trees, and tree decomposition techniques.

---

## Subtopics & Planned Modules

1. **`tree-traversals/`**: Tree DFS/BFS, subtree sizes, depths, and parent pointers.
2. **`tree-diameter-and-center/`**: Two-DFS algorithm and tree DP diameter formulation.
3. **`binary-lifting-lca/`**: Lowest Common Ancestor in $O(\log N)$ query with $O(N \log N)$ preprocessing.
4. **`euler-tour/`**: Flattening trees into arrays for subtree updates/queries via Segment Trees / Fenwick.
5. **`tree-dp/`**: Bottom-up dynamic programming on trees (e.g. Tree Matching, Vertex Cover).
6. **`rerooting-dp/`**: Two-pass DFS calculating optimal answer when any vertex $v$ can serve as the root.
7. **`heavy-light-decomposition/`**: Heavy-Light Decomposition (HLD) mapping arbitrary paths to $O(\log N)$ array segments.
8. **`centroid-decomposition/`**: Divide-and-conquer on trees by finding centroids, solving path counting problems in $O(N \log N)$.
9. **`virtual-trees/`**: Auxiliary tree construction for $K$ marked vertices in $O(K \log K)$.
10. **`prufer-sequences/`**: Bijection between labeled trees and sequences, Cayley's formula.
